## ملفات المشروع

- `source/java/` يحتوي كود الرسم، استرجاع النص، الترجمة الأونلاين، وتجهيز التنزيلات المترجمة.
- `source/smali/` يحتوي تعديلات الربط داخل APK، ومنها القارئ، كاش الصفحات، وقائمة إعادة الترجمة.
- `patches/` يحتوي تغييرات الربط بقارئ الصفحات ومنزّل الفصول وشاشة إعدادات التنزيل.
- `source/stubs/` يحتوي تعريفات مساعدة للترجمة البرمجية. مكتبات Android وKomikku الفعلية تأتي من حزمة التطبيق الأساسية.
- `verification/` يحتوي اختبارات المكوّنات التي شُغلت خارج أندرويد.

هذا المشروع يحفظ ملفات تعديل APK المبني على [Komikku](https://github.com/komikku-app/komikku). راجع [ملاحظات البناء](BUILD.md) لترتيب ملفات DEX ومتطلبات إعادة بناء الحزمة.
